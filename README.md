# TMA3084 SELAB - Lab 1: Pizza Order Calculator

A simple Dart console program that calculates the total payment for a pizza order.

## Features
- Displays pizza prices: Small = 5 USD, Medium = 7 USD, Large = 10 USD
- Asks the user for pizza size and quantity
- Uses a `switch` statement to set the price based on the size
- Uses `while` loops for input validation and continuous ordering

## How to Run
```
dart main.dart
```
